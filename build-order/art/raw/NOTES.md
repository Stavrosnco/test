## Versions

- ComfyUI 0.20.1 (portable, `H:\AI\ComfyUI`), frontend 1.42.15, workflow templates 0.9.63
- Embedded Python 3.13.12, PyTorch 2.11.0+cu130, NVIDIA driver 616.92, RTX 4070 SUPER 12 GB, Windows 11 Pro
- Diffusion model: `flux-2-klein-4b-fp8.safetensors` (distilled; sha256 97ed34fe0567…)
- Text encoder: `qwen_3_4b.safetensors` (sha256 6c671498573a…)
- VAE: `flux2-vae.safetensors` (sha256 868fe7b343cc…)
- Sampling (template defaults for the distilled model): euler, Flux2Scheduler 4 steps, CFGGuider cfg 1, negative = ConditioningZeroOut(positive)

The API workflow is the "Text to Image (Flux.2 Klein 4B Distilled)" subgraph of the built-in template `image_flux2_klein_text_to_image`, flattened to API format by hand. Node ids and values are the template's own. The only change is `unet_name`, which points at the fp8 file instead of `flux-2-klein-4b.safetensors`.
